Once per machine

Set up this machine

Nix runs the CLI. Tailscale puts you on the private network. After this, creating a box is two commands.

1

Install Nix

xyne-boxes runs entirely through Nix. If you do not have it yet, install it with nixone.

2

Install Tailscale

You need the Tailscale CLI so you can join the Juspay network. On macOS, install it from the Mac App Store. On Linux, use the official Linux packages or your distro’s Tailscale module. tailscale --help should print something.

macOS: CLI missing after the App Store install

The App Store build does not always put the CLI on your PATH. Paste this once:

$mkdir -p /usr/local/bin
printf '#!/bin/sh\nexec /Applications/Tailscale.app/Contents/MacOS/Tailscale "$@"\n' > /usr/local/bin/tailscale
chmod +x /usr/local/bin/tailscale
3

Join the network

This opens a browser so you can sign in.

$sudo tailscale up --login-server=https://headscale.nixos.asia --hostname $(hostname -s)
Every day

Create a box and jump in

Pick a name. The first command builds the box; the second drops you into a shell as toor.

1

Create it

$nix run https://github.com/juspay/xyne-boxes/archive/main.zip create <name>
First time (and about once a week) you will sign in

The terminal prints a link and a short code. Open google.com/device, enter the code, and sign in with your Juspay Google account. That issues the SSH certificate. No keys to copy onto the box.

2

Connect

$nix run https://github.com/juspay/xyne-boxes/archive/main.zip connect <name>
Need agent forwarding for git push from the box?

Load your laptop key into the agent first, then connect.

$eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
Prefer ssh <name> instead of connect

Do this once. After that, plain ssh <name> works for every box you create.

$mkdir -p ~/.ssh
grep -qxF 'Include ~/.pu-state/*/ssh_config' ~/.ssh/config 2>/dev/null \
  || printf '\nInclude ~/.pu-state/*/ssh_config\n' >> ~/.ssh/config
Reference

Commands

Every command is nix run https://github.com/juspay/xyne-boxes/archive/main.zip <command>. Copy buttons paste that full invocation.

CommandWhat it does
create <name>
Create a box
connect <name>
SSH into a box. Also renews your certificate when it expires.
list
List your boxes
fork <source> <name>
Clone an existing box
destroy <name> …
Destroy one or more boxes
version
Print bash, ssh, and step-cli versions
What you get

Inside the box

Every box is an Incus container cloned from a loaded NixOS image — not a bare machine.

Ready to work

git, vim, tmux, direnv, starship, and more. VS Code Remote works out of the box.

Warm Nix

Flakes are on and the box shares the host’s /nix/store. Common Juspay dev-envs are pre-cached.

Your home persists

You land as toor. The home directory survives stop/start. It is gone only when you destroy.

New to Nix?

Start at nixos.asia/nix-first. Next step: home-manager via nixos-unified-template.

If something fails

Help

Access expired

Certificates last about a week. When one lapses, reconnecting looks like this:

pu@pu: Permission denied (publickey,keyboard-interactive). Connection closed by UNKNOWN port 65535

Nothing is broken. Run connect again and sign in the same way as the first time — about 20 seconds, then you are good for another week.

$nix run https://github.com/juspay/xyne-boxes/archive/main.zip connect <name>

GitHub 403

Rate limit. Turn the VPN off and try again. If it keeps happening, set up a GitHub token for a higher limit.
